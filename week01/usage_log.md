### 질문 및 답변 내용 정리
- Python에 C/C++의 switch-case문과 비슷한 문법 있었는지 확인
    - 전통적인 switch-case 문법은 없다.
    - Python 3.10부터 match-case가 추가되어 비슷한 역할으로 기능할 수 있다.

- 작성한 코드의 개선 사항 확인
    - filter_over 함수에서 새로운 리스트의 변수명을 overNumbers로 두었는데, Python에서는 over_numbers로 쓰는 게 권장된다.

- Python의 naming rule 추가 확인
    - 변수, 함수: snake_case
    - 클래스: PascalCase
    - 상수: UPPER_SNAKE_CASE
