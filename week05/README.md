## 5주차 과제 legacy_report.py 하드코딩 리팩터링

### 1. 위험 요소
- API 키 및 DB 비밀번호가 유출될 수 있는 위험이 있다. 원본 legacy_report.py에는 API 키와 DB 비밀번호가 문자열로 하드코딩 되어 있었다. 때문에 해당 코드가 github의 공개 저장소에 올라가면 누구나 이를 보고, 사용할 수 있게 된다.
- 타인이 이를 악용하면 API 키 대량 호출로 인한 과금 발생, 사용 한도 소진으로 인한 서비스 중단이 발생할 수 있고, 키에 연결된 계정, 데이터 접근 권한이 위협받는다. 한편 DB에 저장된 민감한 내부 정보가 유출되는 사고 또한 발생할 수 있다.

### 2. 수정 사항
- API 키와 DB 비밀번호 값은 비밀로 유지해야 하므로 별도 파일(.env)에 두고, 코드는 실행 시점에 그 파일에서 값을 읽어오도록 하였다.
- MODEL과 REPORT_MONTH는 공개되어도 보안상 문제는 없으나, 실행할 때 바뀔 수 있는 설정값이므로 .env 파일로 함께 옮겼다.
- .env 파일은 .gitignore에 등록하여 Git이 추적하지 못하게 하였다.

### 3. 실키가 1차 커밋으로 노출되었을 시 올바른 대응 절차
- 즉시 해당 키를 폐기하고 새 키를 재발급받는다. 새 키는 올바른 방법으로 관리하도록 한다.
