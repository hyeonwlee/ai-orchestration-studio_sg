### 2.1. Python의 random 모듈
- **질문 배경 및 입력 프롬프트**: assignment2의 mock_llm.py 코드를 작성함에 있어 여러 선택지 중 랜덤한 결과를 얻고 싶을 때 어떤 함수를 사용하는 것이 적절할지 알고자 하였다.
    > 입력 프롬프트: random 모듈에 대해 자세히 설명해 주십시오.

- **AI 답변 및 학습 내용**:
    - Python의 random 모듈은 난수(random number)를 생성하거나, 여러 항목 중 무작위로 선택하거나, 순서를 무작위로 섞을 때 사용하는 표준 라이브러리이다.
    - 주요 함수 - 숫자 생성
        - random.random(): 0.0 이상 1.0 미만의 실수 반환
        - random.uniform(a, b): 두 값 사이의 실수 반환
        - random.randint(a, b): 양 끝을 포함한 정수 중 하나 반환
        - random.randrange(start, stop, step): range(start, stop, step) 중 하나 선택하여 반환
    - 주요 함수 - 항목 선택 및 순서 섞기
        - random.choice(seq): 시퀀스 항목 하나 반환
        - random.sample(seq, n): 시퀀스에서 중복 없이 n개를 선택하여 구성한 새 리스트 반환
        - random.shuffle(seq): 시퀀스 원본 변경, 반환값 없음
    - 일반적으로 난수를 생성할 때마다 결과가 달라지지만, random.seed()를 사용하면 같은 초기 상태에서 동일한 난수 생성 과정을 재현할 수 있다.
    - 보안이 필요한 비밀번호, 인증 토큰, API 키 등을 만들 때는 random 말고 secrets 사용하여라.

- **적용 내용**: assignnent2/mock_llm.py에서 의도한 확률대로 불량 응답을 만들기 위해, 불량 유형 중 하나를 랜덤으로 선택할 수 있게 하기 위해 random.choice() 사용하였다.

- **AI 답변 및 학습 내용**:
    - 파이썬에는 설명을 적는 대표적인 방법이 주석, 독스트링 두 가지 있다.

    - 독스트링도 한 줄이라면 큰따옴표 하나로 쓸 수 있긴 하나, 큰타옴표 세 개는 여러 줄의 문자열을 작성할 때 편리하기 때문에 관례적으로 많이 사용한다.


### 2.3. json.loads() 함수
- **질문 배경 및 입력 프롬프트**: 강의자료의 코드 중 try-except 문에 json.loads()가 사용된 것을 보고, 어느 경우에 예외를 발생시키는지 정확히 알고자 해당 함수의 사용법을 질문하였다.
    > 입력 프롬프트: json.loads 함수의 인자로는 무엇이 들어갈 수 있습니까?

- **AI 답변 및 학습 내용**:
    - Python의 json.loads() 함수에는 JSON 형식으로 작성된 문자열(str) 또는 UTF-8, UTF-16, UTF-32로 인코딩된 바이트열(bytes), 바이트 배열(bytearray)을 넣을 수 있다.
    - dict, list 자체를 넣는 것은 불가능하다. JSON 문법에 맞는 문자열을 넣어야 하고, json.loeads()는 그 문자열의 형태에 따라 서로 다른 파이썬 객체(dict, list, str, int 등)를 반환한다. 
    - JSON 문법의 예시로는 문자열에 큰따옴표(")를 사용하고, True가 아니라 true를 사용한다는 것이 있다.

- **적용 내용**: assignment2/classify.py에서 json.loads() 함수를 사용하면서, 그 인자로 오로지 사전 형태의 문자열만 남겨야 하는 이유를 보다 잘 이해했다.


### 2.4. json.JSONDecodeError
- **질문 배경 및 입력 프롬프트**: 강의자료의 코드 중 try-except 문을 보고, except의 경우 해당 에러가 무엇을 표현하는 것인지 정확히 알고자 질문하였다.
    > 입력 프롬프트: e.msg로 출력되는 것들이 무엇이 있는지, 무슨 뜻인지 알고 싶어요.  
    > e.msg로 출력되는 것들이 무엇이 있는지, 무슨 뜻인지 알고 싶어요.

- **AI 답변 및 학습 내용**:
    - json.JSONDecodeError as e에서 as e는 발생한 예외 객체를 e라는 변수에 담는 역할을 한다.
    - e로는 다음과 같은 정보를 확인할 수 있다.
        ```Python
        except json.JSONDecodeError as e:
            print(e)        # 오류 원인과 위치 함께 표시
            print(e.msg)    # 오류 원인
            print(e.lineno) # 오류가 발생한 줄 번호
            print(e.colno)  # 오류가 발생한 열 번호
            print(e.pos)    # 문자열 내 오류 위치
        ```
    - 자주 만나는 e.msg 메시지는 다음과 같다.
        e.msg 메시지 | 의미 | 흔한 원인
        --- | --- | ---
        Expecting value	| 값이 와야 하는데 없음 | 빈 문자열, 값 누락
        Expecting property name enclosed in double quotes | 객체의 키는 큰따옴표로 감싸야 함	 | 작은따옴표 사용, 키에 따옴표 없음
        Expecting ':' delimiter | 콜론(:)이 있어야 함 | 키와 값 사이에 콜론 누락
        Expecting ',' delimiter | 쉼표(,)가 있어야 함 | 항목 사이의 쉼표 누락
        Unterminated string starting at	| 문자열이 끝나지 않음 | 닫는 큰따옴표 누락, JSON이 잘림
        Extra data | 정상 JSON 뒤에 불필요한 데이터가 있음 | JSON 뒤에 다른 텍스트가 붙음
        Invalid \escape | 잘못된 이스케이프 문자 | JSON 문자열 안의 잘못된 역슬래시
        Invalid control character | 문자열에 허용되지 않는 제어 문자가 있음 | 문자열 안에 이스케이프되지 않은 줄바꿈 등
